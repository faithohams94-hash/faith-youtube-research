# Rise & Ruin: Channel Kit

**Niche:** countries' economies and geopolitics: debt crises, collapses, "miracles" that went wrong.
**Style:** 15–18 minute documentary explainers as illustrated 2D animated documentaries with real maps and charts (`STYLE-GUIDE.md`).
**Goal:** YouTube Partner Program in 90 days (`../channel-research/MONETIZATION-STRATEGY-90-DAYS.md`).

## 7. Setup checklist (do these in order)

- [ ] Create the channel as a **Brand Account** in your Google account, so you can add managers later.
- [ ] Set name, handle, logo, banner and watermark.
- [ ] **Verify your phone number** (Studio → Settings → Channel → Feature eligibility). This unlocks **custom thumbnails and videos longer than 15 minutes**, which you need.

- [ ] Set **country of residence** (Settings → Channel → Basic info). This affects monetization eligibility.
- [ ] Add the description, keywords, links and email.
- [ ] Create the 6 playlists.
- [ ] Set the upload defaults.
- [ ] Turn on **intermediate and advanced features** (advanced features can take a few days or need ID or video verification).
- [ ] Prepare an **AdSense** account early, so you're ready the day you qualify.
- [ ] Upload the trailer, then set it as the trailer for people who haven't subscribed.

| 7 | 4 | How to Destroy Africa's Fastest-Growing Economy | MIRACLE-GONE-WRONG | BOOM TO **DEFAULT** | E. Leader + burning country |
| 8 | 4 | Why Turkey's Inflation (Still) Won't Stop | WARNING | MONEY **MELTING** | B. Red country + fire |

**Bold** = the yellow word. Each title still goes through `MASTER-TITLE-PROMPT.md` to test alternatives, and **every key fact must be checked** (for example Japan's debt-to-GDP ratio, Ethiopia's default date, Nigeria's fuel imports) before scripting.

**Production pipeline for each video:**
1. `MASTER-TITLE-PROMPT.md`: final title
2. `MASTER-THUMBNAIL-PROMPT-V2.md`: 2–3 thumbnails
3. Research: IMF, World Bank, central bank, news explainers. Save the links.
4. `MASTER-SCRIPT-PROMPT-V2.md`: script, visual cues, fact-check list
5. Fact-check, then record the voiceover
6. Generate visuals in Flow (`MASTER-IMAGE-PROMPT-V2.md`) and animate in CapCut (illustrated scenes, maps, charts)
7. `MASTER-DESCRIPTION-PROMPT.md`: description, chapters, tags, pinned comment, Shorts captions
8. Publish, then fill in `video-tracker.csv` after 7 days

| Item | Value |

| Gender / age feel | Female, sounds 30–45 |
| Reference sample | `voice/sara-reference-sample.mp3` (the Sri Lanka test paragraph) |
| Measured on the sample | About 153 words per minute, about 0.5 s pauses between sentences, −14.7 LUFS, steady volume (1.9 LU variation), average pitch about 180 Hz |
| Model | _[fill in]_ |
| Stability | _[fill in, starting point 50–60%]_ |
| Similarity | _[fill in, starting point 75–85%]_ |
| Style exaggeration | _[fill in, starting point 0–10%]_ |
| Speed | _[fill in, starting point 1.0]_ |

**Rules**
- Use the same voice and settings in every video. Never switch.
- Generate one paragraph at a time, and regenerate only the lines that sound wrong.
- After twist lines ("But here's the thing."), start the next sentence on a new line to give it a pause.
- Write tricky numbers in words where needed ("thirty-six trillion dollars").
- A paid ElevenLabs plan is required for commercial use (check the current terms).
- If ElevenLabs ever removes the voice from the library, add it to "My Voices" now so you keep access, and keep this reference sample to match a replacement.
